## What changed

`spec-creator` adds a requirement coverage gate: every `US-n` / `NFR-n` must be named by at least
one AC. A requirement that no verifiable AC can cover (for example "should be fast" with no target)
is listed under Open questions as `requirement without AC`. The spec then stays `draft` and is not
ready for planning. The change is backward compatible. See [CHANGELOG](../../plugins/sdd-engineering/CHANGELOG.md).
